# Sinh học học đường

Website học tập sinh học bằng tiếng Việt dành cho học sinh.

## Nội dung

- Thư viện 6 chủ đề sinh học cốt lõi
- Từ điển 18 thuật ngữ với tìm kiếm và bộ lọc
- Giao diện responsive cho máy tính và điện thoại
- Không cần cài đặt; mở trực tiếp `index.html`

Website tự động được xuất bản bằng GitHub Pages sau mỗi lần cập nhật nhánh `main`.
